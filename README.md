# 🧼 Clean Code - Boas Práticas em Desenvolvimento

Este repositório tem como objetivo documentar e demonstrar os aprendizados adquiridos durante um curso de **Clean Code**. Aqui você encontrará exemplos práticos das melhores práticas de codificação para tornar o código mais **legível, manutenível e eficiente**.

---

## 📌 Conceitos Abordados

    1. Boas Práticas de Código- Como organizar e estruturar seu código corretamente.
    2. Nomenclatura de Variáveis - A importância de nomes descritivos e intuitivos.
    3. Uso de Booleanos - Como evitar ambiguidades e melhorar a legibilidade.
    4. Causa vs Efeito - Como organizar funções para que sejam previsíveis e fáceis de entender.
    5. Regras e Convenções - Aplicação de princípios que melhoram a qualidade do código.
    6. Números Mágicos - Como evitar números soltos no código e utilizar constantes nomeadas.
    7. Parâmetros e Desestruturação - Estratégias para melhorar a legibilidade e evitar funções com muitos argumentos.
    8. Comentários - Quando e como utilizá-los corretamente.
    9. Syntax Sugar - Melhorando a escrita do código com recursos modernos da linguagem.

---


## 🎯 Objetivo

- Escrever códigos **mais limpos, legíveis e manuteníveis**.
- Reduzir a **complexidade e redundância** no código.
- Aprimorar as habilidades de **boas práticas de desenvolvimento**.
